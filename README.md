# 🐾 Patinhas — Landing Page de Adoção Responsável

Projeto desenvolvido para o **Desafio 01 — Tire sua Ideia do Papel**.

A proposta é criar uma landing page responsiva, acessível e publicada no GitHub Pages utilizando apenas **HTML5 e CSS3**, sem JavaScript, CSS inline ou tag `<style>`.

---

## 🌷 Sobre o projeto

A **Patinhas** é uma ONG fictícia criada para conectar animais resgatados a pessoas interessadas em adoção responsável.

O projeto foi inspirado em uma linguagem visual leve, acolhedora e moderna, utilizando:

- estrutura em blocos / estilo bentô;
- tons pastéis;
- tipografia limpa;
- cards de adoção;
- galeria de imagens;
- seção institucional;
- informações de contato.

## ♿ Acessibilidade

O projeto utiliza boas práticas básicas de acessibilidade:

- link "Pular para o conteúdo";
- textos alternativos (`alt`) nas imagens;
- navegação identificada com `aria-label`;
- foco visível para navegação por teclado;
- apenas um `<h1>`;
- hierarquia semântica de títulos;
- contraste entre texto e fundo;
- suporte a `prefers-reduced-motion`.

---

## 📱 Responsividade

A página foi construída com Grid e Flexbox.

Breakpoints principais:

- Desktop: layout completo;
- Tablet: grids passam para duas colunas ou uma coluna;
- Celular: conteúdo reorganizado em uma coluna, sem rolagem horizontal.

## 🤖 Como a IA foi utilizada

A IA foi utilizada como **apoio**, não como substituição do entendimento do código.

### Prompt utilizado

> "Usando o layout da referência como guia, crie uma landing page para uma ONG fictícia de adoção chamada Patinhas. O projeto deve usar apenas HTML5 e CSS3 externo, sem JavaScript, CSS inline ou tag style. Use HTML semântico, responsividade, acessibilidade, cards de adoção, galeria, seção sobre, contato e comentários que facilitem a explicação do código."

### Como a IA ajudou

- Sugestão de paleta e sistema visual;
- Revisão de responsividade;
- Verificação de requisitos de acessibilidade;
- Organização e comentários do CSS;
- Sugestão de estrutura do README.

### O que foi revisado manualmente

Pontos que foram checados durante o desenvolvimento:

1. Por que cada tag semântica foi usada;
2. Como o Grid e o Flexbox organizam a página;
3. Como os media queries alteram o layout;
4. Como as variáveis CSS deixam o código mais organizado;
5. Como os atributos `alt` e `aria-label` ajudam na acessibilidade.
